# Marco de Estrategia de Seguridad

Repositorio de la GitHub Page para la publicación del libro **Marco de Estrategia de Seguridad**.

## 🌐 Sitio Web

La página del libro está publicada en GitHub Pages:  
**https://gmddmg.github.io/marcoestraegiaseguridad/**

## 📄 Actualizar el enlace al PDF

Para actualizar el enlace de descarga del PDF, edita el archivo `index.html` y reemplaza la URL de ejemplo en la siguiente línea:

```html
<a class="btn-download" href="https://example.com/marco-estrategia-seguridad.pdf" ...>
```

Cámbiala por la URL directa a tu archivo PDF, por ejemplo:

```html
<a class="btn-download" href="https://drive.google.com/uc?export=download&id=TU_ID_DE_ARCHIVO" ...>
```

## ⚙️ Configuración de GitHub Pages

1. Ve a **Settings** → **Pages** en este repositorio.
2. En **Source**, selecciona la rama `main` (o `master`) y la carpeta raíz `/`.
3. Guarda los cambios. La página estará disponible en unos minutos en la URL indicada arriba.
